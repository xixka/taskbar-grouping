## 2. 任务栏层面的直接证据（UIA 按钮枚举）

通过 Windows PowerShell 5.1 UIAutomation 枚举任务栏按钮名称（工件
`taskbar-buttons-*.txt`），同一 runner 会话内三种状态：

| 状态 | 任务栏按钮（Notepad 相关） | 含义 |
|---|---|---|
| 线路一（ungroup）压测中 | **15 个** `Notepad - 1 running window` + `Taskbar overflow menu` | 每窗口独立按钮（"1 running window"），超出宽度部分进溢出菜单 → **取消分组生效** |
| 线路二（group）压测中 | **1 个** `Notepad - 50 running windows` | 50 窗合并为单组 → **自定义分组生效** |
| 全量还原后 | **1 个** `Notepad - 50 running windows` | 回到 Windows 原生合并行为（50 个原生记事本默认同组合并）→ **还原干净** |

3. **Explorer/自管 AUMID 应用的长时行为**：CI 仅观测 6 s；真机需覆盖切换标签、新建窗口、
   最小化恢复后是否回写。

   已知风险：纠偏需 Windhawk mod 的翻译层钩子，B+ 无此层）。
